# 现场操作单（方向 A：PC 推送 · 2026-10-11）

> 所有命令都是**复制粘贴**，不用手敲。哪一行的开头写了【在哪台机】，就在哪台的"终端"里粘贴回车。
> 终端怎么开：Windows 上开始菜单搜 **Git Bash**（或 cmd / PowerShell）；盒子上就是 SSH 进去后的黑窗口。
>
> 🚨 **最高级安全警示（2026-10-12）：采集 PC 上的一切数据文件——不改、不移、不删、不重命名；只允许复制，原有文件状态不得改变。**
> （本套工具本来就只"读"数据：推送器只复制；日志/密钥只写在用户目录；唯一的新增写入是东华软件自己往专用导出目录 `D:\DH_export` 写出的**新**文件。）
>
> 总则：**盒子只动 `~/dh-lab` 一个目录**；任何东西想撤：`docker rm -f dh-collect && rm -rf ~/dh-lab`（盒子还原）。

## 推送全流程（只走原生格式 · 谁碰谁一眼看懂）

```text
东华软件数据目录（原始数据文件原地不动，谁都不碰）
   │ 抓取器：只读复制「新的、已写稳的」.dat / .dhsln
   ▼
D:\DH_export\native\   ← 中转筐（保留原实验文件夹结构）
   │ 计划任务 dh-grab：每 1 分钟抓一次
   │ 计划任务 dh-push：每 1 分钟推送一次，成功后**删除自己那份中转副本**（PC 不留数据副本）
   ▼
盒子 ~/dh-lab/inbox/ → 容器 dh-collect（每 30 秒扫一遍）
   ▼
~/dh-lab/outbox/（parsed/*.json + 摘要.md）→ 大模型 / Agent
```

**四个性质**：**源只读**（抓取器只复制，绝不改/移/删原文件）；**只传新**（抓过的不再抓；推完归档，不重传大文件）；**单向**（盒子永远没有 PC 的写权限）；**去重**（盒子按内容指纹去重，推多次也只记一次）。

## 第 1 步 · 把工具拷上盒子（在【笔记本】的 Git Bash 里）

**✅ 已确认：盒子 IP = `10.201.9.180`**（2026-10-12 实拍 + 连通实测：SSH 22 ✅、模型服务 12345 ✅、ping ✅）。
所以第 1、2 组现在**就能从笔记本远程做完**。下面"拿 IP"的三条路留作备用（万一以后 IP 变了）。

**（备用）先拿盒子的 IP**（本机实测：`ty1200` 这个名字在校园网 DNS 里**没有登记**，解析不了——所以直接用 IP）：

**① 到盒子跟前（推荐）**：接上 HDMI 显示器 + USB 键盘 → 登录 `admin` / `huangkun123` → 运行：

```bash
hostname -I
```

输出里**第一个不是 172.17 开头**的就是盒子 IP（形如 `10.201.x.x`）。

**② 备选：从新威测试机（10.201.47.169）看**——盒子一直连着它的 502 端口。在它上面开 cmd：

```bat
netstat -an | findstr 502
```

`ESTABLISHED` 那一行的**外部地址**就是盒子的 IP。

**③ 顺手做（可选、一劳永逸）**：用**管理员权限**编辑 `C:\Windows\System32\drivers\etc\hosts`，加一行（IP 换成实际的）：

```
10.201.x.x    ty1200
```

——之后本文档里所有 `ty1200` 命令**原样可用**；没加的话，把下文所有 `ty1200` 替换为盒子 IP 即可。

（验证：`ssh admin@<盒子IP> "hostname"` 应打印出 `ty1200`。）

然后把工具拷上去（两条命令）：

```bash
ssh admin@ty1200 "mkdir -p ~/dh-lab"
scp -r "/f/GitHub项目/通讯协议/dh_tools" admin@ty1200:~/dh-lab/tools
```

> U 盘也行（盒子后面有 USB 口）：插上后在盒子上把 `dh_tools` 整个文件夹拷到 `~/dh-lab/tools`。
> 不过 **scp 更快更省事**，推荐上面两条命令。

## 第 3 步 · 采集 PC：装"推送器"（在【采集 PC】的 cmd/PowerShell 里）

生成密钥（一路回车；采集 PC 是老版 OpenSSH，`-t ed25519` 会报 unknownkeytype，所以用 RSA）：

```bat
ssh-keygen -t rsa -b 4096
```

把公钥交给盒子（`<盒子IP>` 换成第 2 步抄的）：

```bat
type %USERPROFILE%\.ssh\id_rsa.pub | ssh admin@<盒子IP> "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys"
```

试推一份（随手找个 txt 文件，或先跳过，等有导出文件再试）：

```bat
scp "D:\DH_export\某个文件.txt" admin@<盒子IP>:/home/admin/dh-lab/inbox/
```

装 B 方案的四个文件（抓取器 + 推送器）：

1. 四个文件放到采集 PC 的 `D:\`（推荐直接从盒子取，四条命令）：
```bat
scp admin@10.201.9.180:/home/admin/dh-lab/tools/push_to_box.bat D:\
scp admin@10.201.9.180:/home/admin/dh-lab/tools/dh_push.ps1 D:\
scp admin@10.201.9.180:/home/admin/dh-lab/tools/dh_grab.bat D:\
scp admin@10.201.9.180:/home/admin/dh-lab/tools/dh_grab.ps1 D:\
```
2. **告诉抓取器"软件数据目录"在哪**：在 `D:\` 新建文本文件 `paths.txt`，内容只有一行，例如 `D:\东华数据`。
   不确定目录在哪：PowerShell 里跑
   ```powershell
   Get-ChildItem D:\ -Recurse -Depth 4 -Filter *.dhsln -ErrorAction SilentlyContinue | Select-Object -First 3 -ExpandProperty DirectoryName
   ```
3. 建目录不用你管：中转筐 `D:\DH_export\native`、归档 `_sent`、日志与账本 `_state` 都由脚本自动创建。
4. 建两个计划任务（**管理员** cmd；= 每 1 分钟各跑一次）：
```bat
schtasks /create /tn dh-grab /tr "D:\dh_grab.bat" /sc minute /mo 1 /f
schtasks /create /tn dh-push /tr "D:\push_to_box.bat" /sc minute /mo 1 /f
```
5. 手动各跑一次看结果：先 `D:\dh_grab.bat`，再 `D:\push_to_box.bat`；日志在 `D:\DH_export\_state\`（`dh_grab.log` / `dh_push.log`）。

## 常见问题

| 问题 | 答案 |
|---|---|
| 命令要手敲吗？ | 不用。全部复制粘贴。 |
| 命令在哪运行？ | 【笔记本】= 你电脑上的 Git Bash；【盒子】= `ssh admin@ty1200` 进去后的窗口（或接显示器键盘）；【采集 PC】= cmd/PowerShell。 |
| U 盘行不行？ | 行（盒子后面有 USB 口），但 scp 两条命令更快。 |
| 盒子需要装东西吗？ | 不需要。脚本是零依赖的；容器化会用盒子现成的 Docker。 |
| 出问题怎么撤？ | `docker rm -f dh-collect && rm -rf ~/dh-lab` —— 盒子恢复原样。 |
| 盒子密码？ | `huangkun123`（登盒子用；配好推送器后日常不用输——推送走密钥）。 |
| 会不会动到采集 PC 的原文件？ | **不会**（最高级规则）：只复制、不改动；全链路没有移动/改名/删除动作。 |
| 任务计划窗口一闪一闪？ | 正常：每 1 分钟黑窗一闪（秒级），不干扰采集软件和实验。 |
| PC 上会不会越堆越多？ | 不会：推成功后中转副本立即删除；只有 `_state\` 里的日志/账本在缓慢增长（每文件一行，可随时清空）。 |
| 盒子上只认哪些文件？ | 只认 `.dhsln`（`.dat` 先归档、待标定后启用）；**txt 已被完全忽略**（实测：放进去计数不动）。 |
| 用不了 docker（提示"当前用户没有权限"）？ | `admin` **已在 sudo 组**（= 你本人就是管理员）。想让"容器版"生效（重启自恢复）：盒子上跑 `sudo usermod -aG docker admin` → **关掉终端重新登录** → 再跑一次一键脚本。不做也不影响（直跑照用）。 |

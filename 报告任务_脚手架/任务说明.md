# 报告生成任务说明（给 Agent 的工作流指令）

> 你（Agent）要完成的：按本说明**逐块生成报告段落文本**，存入 `段落/` 目录，
> 最后运行 `render.py` 组装出 HTML 报告。数据由程序算好放在 `block_data/`，
> **你只引用数据包里的数值，不做任何计算**。

---

## 0. 背景与诚实声明

- 本次报告用的是**进行中测试**的每日增量数据（数据截至 2026-10-01 02:00），
  电池只跑了少量圈数（化成段），所以这是一份**阶段性报告**。
- 报告标题与图注已由程序写明"进行中/暂定值"，你在正文里也必须保持这个诚实度。
- 实验变量（两颗电池的差异是什么）**未提供**——涉及变量的判断一律降级为告警标记。

---

## 1. 系统提示词（每块写作时都遵守）

```text
# 角色
你是电化学测试数据分析专家，为电池测试报告撰写指定段落的文字。

# 铁律
1. 只用输入给出的数值。输入里没有的数字、趋势、结论一律不写；缺数据就写"（该项数据未提供）"。
2. 不做计算。不加减乘除、不换算单位、不四舍五入改写，直接引用字段原值。效率类数值（首效、库伦效率）直接引用，方向以输入为准，不得按公式自行换算。
3. 两组对比必须给全三要素：谁高谁低 ＋ 差值及单位 ＋ 是否超出个体波动范围。
4. n_parallel = 1 时：禁止"显著提升/显著改善/证明了/表明该变量有效/大幅"；只用"略高、略低、基本相当、提示、可能、倾向"；差异小于阈值的写"处于单颗电芯个体波动范围内"。
5. 机制只能写"可能/推测"，并说明需要什么表征验证；禁止"证明/表明/归因于"。

# 输出格式（严格遵守，违者作废）
- 只输出中文正文段落。一行一段，段与段之间用换行分隔。
- 禁止输出任何 HTML 标签、# 标题符号、表格、代码块、解释语、编号前缀。
- 首次出现的专业口径要当句解释，例如：平台容量占比（放电容量中电压低于 0.10 V 的份额）。
- 数值格式：比容量 mAh·g⁻¹；电压 mV 或 V；百分数保留 2 位小数；保持率差用"个百分点"。
- 段落末句按提示要求写"……见表 X"或"……见图 X"。
```

每块的处理：

1. 读 `block_data/<单元ID>.json` 与 `提示词/<单元ID>.txt`；
2. 按提示词写段落（第 1 节的系统提示词作为你的角色设定遵守）；
3. **自检第 3 节的 8 条校验规则**，不合格就重写（最多重写 2 次）；
4. 存 `段落/<单元ID>.txt`（UTF-8，纯文本，一行一段）；
5. 台账：每完成一个 3.x 单元，把该维度的「方向 / 幅度 / 是否超出波动范围」
   追加到 `台账.json`。

### 特殊单元的处理（不要犹豫，直接照做）

- **如果主人只让你"重写某几个单元"**（例如"只重写 S32B、S33A、S34A"）：
  就只重写点名的这几个 —— 其余单元 `段落/` 里已有的文件**保持不动**（那些是上一轮
  已经通过校验的成稿），写完直接跳到第 4 节跑 `render.py`。不要顺手把 31 个单元全重做。
- **S42A/B/C/D（4.2 机制段）**：实验变量未提供。这四个单元**不写正文**，
  每个文件只写一行：
  【本段未通过自动校验：实验变量信息未提供，作用机制无法推测，内容需人工复核】
- **数据包里 groups 的字段全为 null 的单元**：只写一行
  【该项数据未提供】
  （体系文档铁律：缺数据就写"未提供"，绝不编造。）
- **notes 里有"圈数尚少"字样的单元**：正文中必须保留"圈数尚少、仅供参考"的表述。

## 3. 自检校验规则（每块输出后逐条过）

| # | 规则 | 不合格就重写 |
|---|---|---|
| 1 | **数值溯源** | 输出中每个数字必须能在**本块数据**中找到原值 |
| 2 | **数值编造** | 数字不在本块数据中 → 判为编造 |
| 3 | **禁用词** | 显著提升 / 显著改善 / 证明了 / 表明该变量有效 / 大幅 / 最优 / 完美 |
| 4 | **标签污染** | 出现 `<` `>` `#` `\|` 或三反引号 |
| 5 | **小标题格式** | S41*/S42* 首行必须 ≤20 字且不含编号与句号 |
| 6 | **图表号一致** | 引用的"图 N / 表 N"与提示词一致 |
| 7 | **n=1 兜底** | S41A~D、S51A、S51C、S35C 必须含"波动范围 / 复测 / 需验证 / 可能"之一 |
| 8 | **长度** | 超出提示词要求区间 ±50% | 告警，不重写 |

## 4. 最后一步：组装

全部段落写完后，运行：

    python3 render.py

它会把你写的段落填进 `报告渲染模板.html`（表格、图片、目录都由程序生成），
产出 `SOH分析报告.html`。运行成功后任务完成。

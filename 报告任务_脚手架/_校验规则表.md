|---|---|---|---|
| 1 | **数值溯源** | 输出中每个数字必须能在**本块数据**中找到原值 | 重试 |
| 2 | **示例数值残留** | 数字能在 few-shot 示例中找到、但不在本块数据中 → 判为照抄 | 重试（优先修这个） |
| 3 | **禁用词** | 出现 显著提升 / 显著改善 / 证明了 / 表明该变量有效 / 大幅 / 最优 / 完美 | 重试 |
| 4 | **标签污染** | 出现 `<` `>` `#` `\|` 或三反引号 | 重试 |
| 5 | **小标题格式** | S41A~D / S42A~D 首行必须 ≤20 字且不含编号与标点句号 | 重试 |
| 6 | **图表号一致** | 引用的"图 N / 表 N"与块设定一致 | 重试 |
| 7 | **n=1 兜底** | S41A~D、S51A、S51C、S35C 必须含"波动范围 / 复测 / 需验证 / 可能"之一 | 重试 |
| 8 | **长度** | 超区间 ±50% | 告警，不重试 |

### 5-B 修复提示词模板

校验失败后，把失败原因**逐条列出**再回灌（只重发系统提示词没用，小模型需要知道具体错在哪）：

```text
【修正任务】你上一次的输出存在以下问题：
{逐条列出，例如：
 1) 出现了本块数据中没有的数值"3.21"；
 2) 使用了禁止词"显著提升"；
 3) 输出了 HTML 标签。}
请重写本段，并严格遵守：
- 只使用【本块数据】中出现的数值；
- 不使用"显著、证明、大幅、最优"等词；
- 只输出纯文本正文，不含任何标签、标题符号、表格或编号。

【重写目标】
{原单元提示词全文}

【本次只输出正文】不要输出标题、编号、解释或任何标记。
```

### 5-C 降级策略

```
第 1 次失败 → 带 5-B 修复提示重试（temperature 0.1）
第 2 次失败 → 再降一档：只发"必含信息清单"最简版提示词 + 数据，不给示例
第 3 次失败 → 输出兜底标记并落盘：
             <p class="note">【本段未通过自动校验：{原因}，内容需人工复核】</p>
             同时把该单元的数据沉淀到 failed_blocks.json，供人工补写或离线重跑
```

**绝不允许"跳过不标记"**——那会静默产出缺内容的报告，比留一条显式告警危险得多。

### 5-D 终极兜底：填空式提示词

如果某个单元反复失败（例如机制段），把它改成"填空题"——把句式写死、只留数据槽位。这是弱模型下最稳的形态：

```text
把下面模板中的【】替换为给定数据值，其余文字一字不改地原样输出，不要增删任何句子：

长循环测试在【rate】倍率下进行，【实验组】组完成【N1】圈有效循环，【对照组】组完成【N2】圈。两组放电比容量均呈【trend】衰减，线性拟合得到的衰减速率分别为【r1】【实验组】与【r2】【对照组】。【实验组】组的绝对容量在全程【level】，但其衰减速率【faster】，两组的容量与库伦效率对比见图 1。
```

## 6 渲染模板使用说明

模板文件：`报告渲染模板.html`（CSS 与 JS 从样例报告原样抽取，改动会破坏版式）。

### 6.1 三类替换

| 类型 | 写法 | 谁来填 |
|---|---|---|
| 单值 | `{{DOC_TITLE}}`、`{{DOC_SUBTITLE}}`、`{{DOC_META_SPANS}}`、`{{DOC_NOTE}}`、`{{TOC_TREE}}` | 程序从配置生成 |
| 块位 | `<!--BLOCK:S31A-->` 等，**独占一行** | 程序整行替换为生成的 HTML 片段 |
| 图表位 | `<!--FIGURE:1-->`、`<!--TABLE:4-->` | 程序整行替换为图表 HTML |

### 6.2 模型文本 → HTML 的转换规则

```
普通行           → <p>行内容</p>
连续以 "- " 开头  → <ul><li>内容</li>…</ul>   （仅 S12 会出现）
小标题行（首行）  → <h3>{编号}  {小标题}</h3>   （仅 S41*/S42* 会出现；编号由程序写，如 "4.1.1  "）
```

### 6.3 图表片段

```html
<!--FIGURE:1--> → <figure><img src="data:image/png;base64,{png}" alt="图 1">
                 <figcaption>图 1  长循环放电比容量与库伦效率随循环圈数变化曲线（含线性拟合）</figcaption></figure>
<!--TABLE:4-->  → <div class="tw"><p class="tcap">表 4  标准化循环性能数据统计（基线为第 4 圈）</p>{table_html}</div>
```

图片由绘图管线（参考 `bts_average_voltage.py`：字体设置、自动图例避让、标签防重叠）生成后 base64 内嵌；表格由程序按数据渲染。**两者都不经模型。**

### 6.4 目录

`{{TOC_TREE}}` 由程序按固定章节清单生成，格式照抄样例报告的 `<li class="l1">` / `<li class="l2">` 结构。不要用模型生成目录。

### 6.5 打印与 PDF

CSS 里已含 `@page{size:A4 portrait;margin:16mm 20mm}` 与打印样式。**渲染脚本传给 Chrome 的页边距必须与 CSS 里这两个值完全一致**，否则右侧文字会被裁掉（样例报告的 CSS 注释里已警告过这一点）。导出 PDF 与"打印"按钮走同一套 CSS。

## 7 上手顺序（建议按这个顺序验证）

| 步骤 | 做什么 | 通过标准 |
|---|---|---|
| 1 | 只跑 **S31A**（数据最全、句式最简单） | 3 次内通过校验，数值与台账一致 |
| 2 | 跑 **S31A/B/C** 三连 | 三段口径一致（基线圈、波动范围表述统一） |
| 3 | 跑 3.2~3.4 全部单元 | 图表号引用无误，无标签污染 |
| 4 | 跑 **S42A~D 机制段**（风险最高） | 每条都绑定实验现象、无"证明/表明" |
| 5 | 跑全流程 + 渲染 | 与样例报告 HTML 并排比对，差异只在措辞层面 |

**参数建议**：`temperature = 0.1~0.3`（报告文字不需要创造性）、`top_p = 0.9`、`max_tokens` 给足（别让长段被截断，截断会触发误判）。

**如果连第 1 步都过不了**：把第 1 章系统提示词再砍到 3 条（只用输入的数值 / 不做计算 / 只输出纯文本正文），并直接上 5-D 的填空式提示词。
